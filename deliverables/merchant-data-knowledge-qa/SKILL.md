# 商家数据问答助手

在用户本机工作目录中处理资料。不得上传原始经营明细、完整 Word 正文或本机文件内容给第三方；只有在用户配置并允许模型 API 时，才传递最小必要的字段映射、脱敏样例、问题和已计算结果。

## 用户问答的只读约束

当用户提出“某客户买过哪些商品”“哪些款库存低”“销售额是多少”等业务问题时，只读取已确认的 active 数据版本并直接回答。不得因为问题不属于既有示例而修改 SKILL.md、脚本、工作簿、资料空间或交付包。

优先使用已确认的字段、关系和本机内存计算完成查询；输出结论及 Sheet、字段、筛选或计算依据。资料缺失、字段未确认或文件完整性校验失败时，说明缺少什么并停止，不要为了回答而修改实现。只有用户明确要求“新增能力”“修改 Skill”“修复代码”时，才进入开发流程。

## 数据版本与确认

每次运行 inspect 都生成一个新数据版本，写入上传时间、文件 SHA-256 指纹和状态。初始状态为 pending_confirmation，不能回答销售额、库存、利润等业务结论。先向用户展示关联键、主日期、金额和库存口径的高风险确认项；用户确认后使用 --confirm-high-risk 再次运行 inspect，使新版本成为 active。新 active 版本会将旧 active 版本标记为 superseded；历史版本保留，不被默认查询。

## 文件完整性

记录上传时间、上传时的源文件修改时间、文件大小和 SHA-256 指纹。每次问答前重新检查这三项；任何一项发生变化，停止回答并提示文件可能已被修改、数据可能不准确，要求用户重新运行 inspect 并确认新版本。

## 运行环境

先检测 Python 3.9+：Windows 依次尝试 `py -3 --version`、`python --version`，其他系统尝试 `python3 --version`。脚本只使用 Python 标准库；不要安装依赖、创建虚拟环境、启动数据库或云端服务。

## 工作流

1. 要求用户选择本机 `.xlsx` 或 `.csv`。`.csv` 只能作为单表使用；跨 Sheet 功能需要 `.xlsx`。
2. 运行扫描，生成字段映射建议和跨 Sheet 关系候选：

   ```powershell
   py -3 scripts/merchant_data_qa.py inspect .\服装批发.xlsx --output-dir .\商家资料空间
   ```

3. 向用户展示候选关系及匹配率。只有用户确认后，才用 `--confirm-relations` 写入资料空间：

   ```powershell
   py -3 scripts/merchant_data_qa.py inspect .\服装批发.xlsx --output-dir .\商家资料空间 --confirm-relations
   ```

4. 回答用户问题。脚本会用已确认关系在内存中计算，并输出答案、Sheet、字段、筛选/计算口径和命中数：

   ```powershell
   py -3 scripts/merchant_data_qa.py ask .\服装批发.xlsx --workspace .\商家资料空间 --question "本周销量前十但库存低于20的款有哪些？"
   ```

5. 不要展示模型内部 Prompt 或完整查询计划。向用户展示结论和必要依据；只有用户要求核对时才展开匹配记录。

## 跨 Sheet 规则

- 只使用 `workspace.json` 中 `confirmed: true` 的关系。
- 候选关系仅为建议；匹配率低、键值重复率过高或一对多/多对多关系不清楚时，要求用户确认或说明业务口径。
- 不猜测唯一 ID、日期、金额、库存、销售额或利润定义。未确认字段不能用于关键结论。
- 本版本不自动关联不同工作簿；不改写原始 Excel，不运行宏，也不计算复杂公式。

## 回答规则

- 数字只能来自本机计算结果，不能补写或估算。
- 没有数据时写“当前上传资料中未找到”；没有规则来源时写“当前资料中未找到”。
- 库存、金额、数量、日期以 Excel/CSV 为准；政策、流程、定义以已生效 Word 为准。冲突时提示冲突，不自行裁决。
- 不提供自动定价、自动补货、财税、薪酬或投资结论；不自动发邮件或平台消息。

## 当前可验证的服装批发问题

使用含有“采购/进货、入库、销售、库存”Sheet 的工作簿，可直接处理：

- 本周销量前十但可售库存低于指定阈值的款；
- 本月各供应商的进货数量和金额；
- 某款的进货、入库、销售、当前库存以及入库减销售与库存是否一致。

如果问题不属于上述模板，先运行 `inspect`，确认字段和关联后，将问题改写成明确的查、筛、算、排、比需求；不得把不支持的推测任务伪装成数据查询。

## 本地产物

指定 `--output-dir` 或 `--workspace` 后，脚本只在该目录写入：

- `workspace.json`：数据文件、Sheet、字段语义和已确认关联；
- `query-audits.jsonl`：每次查询的摘要、依据和结果。

不指定本地目录时，只向终端输出 JSON，不创建文件。用户要求删除资料空间时，删除其指定的资料空间目录及其中产物；不得删除原始数据文件。
